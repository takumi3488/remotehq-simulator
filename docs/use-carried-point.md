# 貯まったポイントの活用方法

## 活用方法1: レンタルに利用

### 概要

貯まったポイント(未利用ポイント)を月額換算することで、残レンタル可能ポイントを超えたレンタルの注文が可能になります。

注文に必要なポイントは月額不足ポイント分とカート内商品のポイント消化期間によって決まります(システムで自動計算されます)。

例えば、残レンタル可能ポイントが500pt / 月の場合、600pt / 月(ポイント消化期間が12ヶ月)の備品はレンタルできません。

![Frame_176.png](https://storage.googleapis.com/remote-hq-production-cms/strapi/upload-plugin/Frame_176_d24794bd4f/Frame_176_d24794bd4f.png)

ただし、貯まったポイント(未利用ポイント)が1200ptあれば、残レンタル可能ポイントが500pt / 月でも600pt / 月(ポイント消化期間が12ヶ月)の備品のレンタルが可能になります。

1200ptのポイントを100pt / 月(12ヶ月分)と換算することで、残レンタル可能ポイントの500pt / 月 と足して、600pt / 月(ポイント消化期間が12ヶ月)の備品がレンタル可能になります。
