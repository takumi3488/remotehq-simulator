# remotehq-simulator

RemoteHQ のレンタル情報を読み込み、新しいレンタルを開始した場合の「貯まったポイント」と自己負担額を月ごとに試算する CLI です。

## 実行方法

リポジトリのルートで実行します。

```sh
go run .
```

またはインストールして実行します。

```sh
go install .
remotehq-simulator
```

初回は、ブラウザで [レンタル状況ページ](https://app.hq-hq.co.jp/remote/mypage/rentals) を開き、開発者ツールの「ネットワーク」タブから `rentals` リクエストの「レスポンス」をコピーして CLI に貼り付けます。貼り付けた内容はキャッシュに保存され、次回以降はキャッシュを使うか確認されます。`n` を入力すれば新しいレスポンスを貼り付けられます。

続けてレンタル月額 (pt) とポイント消化期間 (月) を入力すると、ポイント消化の月次推移と合計が表示されます。

## キャッシュ

キャッシュファイル名は `rentals.html` です。絶対パスの `XDG_CACHE_HOME` が設定されている場合は `$XDG_CACHE_HOME/remotehq-simulator/`、Windows ではユーザーキャッシュディレクトリ配下、macOS などそれ以外では `~/.cache/remotehq-simulator/` に保存します。ファイルは個人情報を含むため、所有者だけが読み書きできる権限で保存します。

## 試算モデル

- 開始日は実行日とし、以降毎月同日 (存在しない日は月末) を各月の判定日とします。
- 月ごとに、残レンタル可能ポイントから先に充当し、不足分を貯まったポイントから消化し、それでも足りない分を自己負担として計算します。
- その月に使わなかった残レンタル可能ポイントは、貯まったポイントに加算されます。
- 利用中 (`USING`) レンタルが消費するポイントは、`paidUpDate` (ポイント消化最終日) の翌日以降、または返却集荷日以降に残レンタル可能ポイントへ戻ります。
- 「ポイントのみで注文可能な上限」は注文時点の判定 (残レンタル可能ポイント + 貯まったポイント ÷ ポイント消化期間) です。サイトの `maxMonthlyPointsForPayingMonthList` と同じ式です。
- 1 pt = 1 円 (税抜) として自己負担を表示します。消費税は合計額に含みません。

仕様の詳細: [貯まったポイントの活用方法](docs/use-carried-point.md)、[自己負担](docs/individual-payment.md)。
